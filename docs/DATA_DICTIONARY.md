# 数据字典与计算口径

## 基本原则

- 当前数据全部为模拟数据。
- 金额默认使用人民币。
- `k/月` 表示税前月薪千元；`万元` 表示年度总额万元。
- 公开招聘报价与员工实际薪酬不是同一数据口径。

## 经营总览

| 指标 | 定义 | 当前口径 |
| --- | --- | --- |
| 人才就绪度 | 关键岗位、关键技能和预算准备度的综合展示分 | 原型展示值，不用于真实决策 |
| 年度新增编制 | 规划期新增正式及等效用工数量 | 68 人 |
| 测算总人力成本 | 固定薪酬、浮动奖金和雇主福利成本之和 | 模拟年度成本 |
| 招聘报价 P50 | 公开职位报价样本的中位水平 | 不是员工实际薪酬 |
| 高风险关键岗位 | 同时具有高业务影响和供给短缺的岗位类别 | 规则标记 |

## 人才地图

| 字段 | 定义 |
| --- | --- |
| 人才指数 | 综合人才供给、技能匹配和招聘效率的 0–100 展示分 |
| 人才供给 | 对候选人才量与匹配度的定性判断 |
| 报价中位 | 模拟公开职位月薪报价的中位值 |
| 招聘周期 | 从职位发布到候选人接受报价的模拟平均月份 |
| 技能热力 | 技能在不同岗位族中的相对重要度，1 为低、5 为高 |
| 市场覆盖率 | 同时满足复合技能要求的模拟人才占比 |

## 薪酬洞察

| 字段 | 定义 |
| --- | --- |
| P25 | 25% 的市场样本低于该水平 |
| P50 | 市场中位数 |
| P75 | 75% 的市场样本低于该水平 |
| 浮动占比 | 目标浮动奖金占年度现金总收入的比例 |
| Compa-ratio | 员工或群体薪酬 ÷ 薪酬区间中点 |
| 市场定位 | 企业计划相对于市场分位采取的薪酬策略 |

Compa-ratio 在当前原型中的提示区间为：

- 低于 0.90：需要关注
- 0.90–1.10：合理区间
- 高于 1.10：需要结合绩效、任职年限和岗位变化复核

## 编制与预算模型

年度预算的原型公式为：

```text
平均基础成本 = 24 + (市场分位 - 50) × 0.12
固定薪酬 = 新增编制 × 平均基础成本 × 城市系数
浮动奖金 = 固定薪酬 × 16%
福利及雇主成本 = 固定薪酬 × 17%
年度总人力成本 = 固定薪酬 + 浮动奖金 + 福利及雇主成本
预算差额 = 2,410 - 年度总人力成本
```

城市系数：

| 城市组合 | 系数 | 原型含义 |
| --- | ---: | --- |
| 核心城市集中 | 1.08 | 人才密度高、成本也更高 |
| 双中心平衡 | 0.99 | 兼顾人才质量与成本 |
| 成本效率优先 | 0.92 | 成本较低，但异地管理风险更高 |

这些系数只用于演示情景分析方法，不是市场研究结论。

## AI 输出字段

| 字段 | 定义 |
| --- | --- |
| 标准岗位 | 将不同写法的职位名称映射到统一岗位分类 |
| 核心技能 | 从 JD 中提取的工具、领域和通用能力标签 |
| 资格要求 | 学历、经验、地点等结构化字段 |
| 置信度 | 解析结果可信程度的原型展示值 |
| 依据 | 生成建议时引用的数据集或模型版本 |
| 限制说明 | 对样本、口径和适用范围的披露 |
