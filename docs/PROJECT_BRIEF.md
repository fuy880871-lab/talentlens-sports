# 项目说明

## 1. 项目目标

TalentLens Sports 是一个体育行业人才与薪酬决策平台原型。它不是通用 HR 系统，而是围绕管理层的具体决策，把市场人才研究、岗位标准化、薪酬对标和组织编制规划连接起来。

目标用户包括：

- 人力资源负责人和 HRBP
- 薪酬与绩效团队
- 人才战略与组织发展团队
- 管理咨询及 HR 数据解决方案顾问

## 2. 案例背景

虚构公司“跃界体育集团”计划从传统赛事运营扩展至数字运动产品与服务。2027 年拟新增 68 个岗位，重点评估上海、北京、深圳和成都四个城市，并在 2,410 万元年度人力预算内完成团队设计。

案例将重点岗位划分为五组：

1. 数字产品与数据
2. 运动科学
3. 内容与赛事
4. 商业拓展
5. 组织与运营

## 3. 分析框架

```text
业务增长目标
    ↓
岗位与能力需求
    ↓
城市人才供给与技能缺口
    ↓
薪酬市场定位与内部公平性
    ↓
编制、城市和预算情景模拟
    ↓
带证据、权衡和限制的管理建议
```

## 4. 关键产品决策

### 把“数据”与“建议”分开

平台先展示人才指数、薪酬分位数和成本测算，再生成管理建议。这样用户可以追溯建议依据，避免把 AI 输出误当作事实。

### 把确定性计算留给公式

编制预算由人数、市场分位与城市系数计算；语言模型只适合解释、归纳和生成建议，不承担金额计算。

### 把 AI 置信度与人工复核写进流程

岗位解析流程包含文本清洗、岗位归一、技能提取和人工复核。低置信度结果应进入人工复核，而不是直接写入岗位库。

### 明确数据边界

公开招聘报价不等于员工实际薪酬；模拟样本不等于市场调查；任何正式结论都需要使用真实、授权且经过质量检查的数据进行校准。

## 5. 当前 AI 实现

当前版本使用本地规则和模拟知识库，以便在无密钥环境中完整演示交互：

- JD 解析：展示标准岗位、技能、资格和稀缺度字段的预期结构。
- 决策助手：根据关键词路由到城市、预算、技能或薪酬主题，并返回建议、依据和限制。
- 安全边界：不处理真实个人数据，不评价个人，不使用敏感属性。

这是一套产品原型，不应被描述为已经训练或部署的机器学习模型。

## 6. 正式化路线

若进入真实业务环境，建议按以下顺序迭代：

1. 制定岗位、技能和薪酬字段标准，并建立数据质量规则。
2. 接入获授权的职位与薪酬数据，保留来源、时间和样本量。
3. 用结构化输出约束大模型，关键字段执行规则校验。
4. 建立人工标注集，分别评估岗位映射、技能提取和建议引用。
5. 对敏感字段、权限、日志、数据保留周期和人工复核建立治理机制。

## 7. 与目标岗位的能力映射

| 目标能力 | 项目证据 |
| --- | --- |
| 行业研究 | 体育人才细分、城市供给与关键技能稀缺度 |
| 薪酬咨询 | 市场分位、Compa-ratio、固定与浮动薪酬定位 |
| 数据解决方案 | 指标体系、交互看板、情景参数与确定性测算 |
| 管理咨询 | 从业务问题到组织方案、成本权衡和行动建议 |
| AI 应用 | JD 结构化、证据化问答、人工复核与安全边界 |
| 沟通呈现 | 管理层总览、可解释建议和项目文档 |

## 8. 局限性

- 所有数据为小规模模拟样本，不能代表体育行业真实市场。
- 城市人才指数和薪酬分位没有外部调查样本支持。
- AI 交互为规则演示，没有真实模型准确率。
- 当前版本没有用户权限、持久化存储和审计日志。
